# Portfolio · Youssef Cherkaoui

Il mio sito personale: sistemista IT a Torino, Wazuh Ambassador e studente di Informatica all'Università di Torino.

**Sito:** https://youssefcherkaoui.github.io/portfolio/

## Struttura

| File | Contenuto |
| --- | --- |
| `index.html` | Le sezioni del sito: chi sono, percorso, strumenti, progetti, formazione, contatti |
| `style.css` | Layout, tipografia (Bebas Neue ed EB Garamond) e versione per telefono |
| `script.js` | Animazioni di entrata e progetti a scorrimento automatico, con pausa |
| `img/` | Foto e schermate dei progetti |

Nessun framework e nessuna build: HTML, CSS e JavaScript scritti a mano, pubblicati con GitHub Pages dal branch `main`.

## Avvio in locale

```bash
python3 -m http.server 8000
```

poi apri http://localhost:8000.
